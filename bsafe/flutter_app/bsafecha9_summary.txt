B-SAFE Project Chat Summary

1) Project Overview
- B-SAFE is a smart building safety platform built with Flutter.
- It contains a Mobile App for on-site workers and a Web Dashboard for company staff.
- The system uses Supabase as the shared cloud backend.
- Main goals:
  - allow workers to report building defects with photos and AI-assisted analysis
  - let company staff review reports and update status
  - keep Mobile App and Web Dashboard synchronized
  - support an inspection workflow with floor plans and project/session data

2) What the Project Does
- Mobile App
  - create defect reports
  - attach photos
  - run AI analysis on images
  - capture GPS/location information
  - view report history and details
  - send follow-up responses
  - update status
  - support manual offline mode and connectivity checking
  - support building inspection / UWB-related workflows
- Web Dashboard
  - view report list and dashboard summary
  - review detailed report records
  - update status
  - add company notes / follow-up messages
- Supabase Backend
  - stores shared report data in the cloud
  - stores inspection session data
  - stores uploaded images and floor plans in storage buckets
  - supports realtime synchronization between devices

5) Important Answers / Conclusions From AI
- The report title is usually generated from AI analysis or fallback logic.
- The main AI prompt for defect analysis is located in the app service code.
- Supabase is used as the central cloud database and storage system.
- Reports store defect data, AI results, status, company notes, and related metadata.
- Inspection sessions store project/session/floor-plan related information.
- Images are stored in Supabase Storage buckets, while the database stores the links/references.
- Realtime syncing is used so Mobile and Web can see the latest data without manual refresh.
- For PPT, it is better to explain database by purpose and flow rather than by raw schema fields.

7) Typical Data Stored in Supabase
- Reports
  - defect report text
  - AI analysis summary
  - photos / photo URLs
  - company notes
  - status and timestamps
  - location information
- Inspection Sessions
  - project name
  - floor / multi-floor references
  - floor plan links
  - inspection payload details
- Storage Buckets
  - report-images
  - floor-plans

8) Typical Problems the Project Solves
- Manual report tracking is slow.
- Mobile and Web can become inconsistent if they do not share the same backend.
- Users need realtime updates so they do not have to refresh manually.
- AI-assisted report creation and analysis reduces manual effort.
- Cloud storage is needed for defect photos and floor plans.

9) Useful Final Summary
- B-SAFE is a cross-platform building safety system.
- It combines a Flutter Mobile App, a Flutter Web Dashboard, Supabase cloud storage/database, AI-assisted defect analysis, and realtime synchronization.
- The project focuses on reporting, tracking, follow-up, inspection management, and keeping all data consistent across devices.
